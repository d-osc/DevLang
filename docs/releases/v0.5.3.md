# DevLang v0.5.3

Native `str == str` and `str != str` now compare contents instead of rejecting the expression. The editor checker uses the same rules. Native strings still use C NUL termination; runtime strings compare their entire contents. Ordering operators remain unsupported.

Package scripts can be invoked with `d NAME`, `d run NAME`, `d --run NAME` or `d -r NAME`. Bare `d check` and `d format` use matching scripts; `d check FILE.dev` keeps the native checker. Arguments and exit codes are preserved. Other built-in names remain reserved for direct invocation; use `d task NAME` or `d run NAME` for collisions.

The Web API example now includes `package.don` and start/format scripts. Real HTTP regressions cover both source engines and package script launch paths.

DevLang VS Code extension 0.2.1 includes DON syntax highlighting, formatting, file icons and language server support. Marketplace publication is independent of the language binary release.

Assets include Windows/Linux x86_64 and ARM64 binaries and offline installers. The Windows single-file GUI installer is x86_64. Native compilation requires a compatible C backend. Installers are unsigned.
