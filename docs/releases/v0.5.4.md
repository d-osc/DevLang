# DevLang v0.5.4

Dev scripts can now be executable. The new `dev` launcher (a second name for the `d` binary) makes `#!/usr/bin/env dev` work: the `#!` line is read as a comment, and arguments after the script path go to the program without `--`. `dev` is included in the `dist/d` bundle. See the shebang example in `examples/howto/shebang.dev`.

The source runtime's numeric plan is faster: integer types up to 64 bits use machine-word operations, assignments of computed values no longer emit extra copies, and the per-instruction closure is gone. A 100M-iteration integer loop runs about 20-25% faster. Results are unchanged between `--engine auto` and `--engine ast`.

Assets include Windows/Linux x86_64 and ARM64 binaries and offline installers. The Windows single-file GUI installer is x86_64. Native compilation requires a compatible C backend. Installers are unsigned.
