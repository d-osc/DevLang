DevLang v0.5.2 includes CLI 0.5.2, compiler 0.4.2 and runtime 0.2.2.

- Add Windows and Linux ARM64 bundles alongside x86_64. Native binaries are built and executed on their target runners; packaging verifies PE/ELF architecture and publishes SHA256SUMS.
- Add JavaScript-style Object prototypes/descriptors and typed aggregate/function callbacks, dynamic Array methods, Math APIs and source prototype cycle collection.
- Bound parser recursion/expression depth and add malformed-source/resource regressions.
- Isolate HTTP handler failures, test real HTTP/HTTPS ingress, and include HTTP supervisor, Windows Job limits, Windows Service configuration and certificate-health tools in CLI/runtime bundles.
- Add interactive source debugging, a VS Code runtime terminal command and updated documentation.

Component archives and offline installers are provided for Windows/Linux x86_64 and ARM64. The single-file Windows GUI installer is provided for x86_64; ARM64 has an offline ZIP installer. Windows executables are unsigned. Native compilation and source C FFI require an installed C backend (Clang/GCC); this release does not bundle TinyCC.

Production tooling improves the source HTTP deployment profile but does not certify arbitrary applications. Configure the actual Windows Service account/permissions, real-hostname TLS certificate/renewal and application soak/recovery tests before public deployment. Job memory limits measure committed memory; RSS is a separate sampled budget.
