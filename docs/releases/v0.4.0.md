# DevLang v0.4.0

This release expands the source runtime and native compiler with managed collections, richer types, C interoperability and threaded tasks.

## Downloads

Choose the `devlang-d` archive for the unified command with both compiler and runtime. Separate `compiler`, `runtime` and `stdlib` archives are also available for Windows x86_64 and Linux x86_64. Verify downloads against the attached `SHA256SUMS`.

Extract the archive and add its directory to PATH:

```sh
d examples/hello.dev
d run examples/features/continuations.dev
d build examples/hello.dev
```

Examples are available in the source archive or repository at this tag. Programs explicitly invoke `main()` after declaring it. Running pure Dev source does not require a native compiler.

## Changes

- Unified `d` CLI with separate source runtime and native compiler packages.
- `for`, structs, payload enums, recursive references and richer pattern matching.
- Generic inference, structural constraints, function values, closures and methods.
- Managed `Ref`, `Vec`, `Slice` and hash-based `Map` collections.
- Enforced `unsafe` boundaries, bounds checks and arithmetic safety checks.
- Runtime C FFI, automatic native dependency preparation, aggregate calls, variadic calls and callbacks.
- Thread-backed tasks, `await`, `ready`, `then` continuations and managed callbacks with user data.
- Optimized runtime numeric execution and documented collection benchmarks.

## Requirements and limits

Windows archives target x86_64. Native compilation and first-time preparation of C source dependencies require Clang or GCC; warm cached FFI dependencies can be reused. Linux archives were tested on Ubuntu 24.04 under WSL and require glibc 2.39 or newer. Linux compiler packages include TinyCC for basic fast builds; advanced C11 task/callback programs require Clang or GCC.

Tasks use OS threads and blocking waits; this is not an async I/O scheduler. Foreign pointer lifetimes remain the caller's responsibility. Raw capturing callbacks have a bounded native slot pool; use `callback_context` with a C user-data API for managed instances and keep the owner alive until calls finish.

Release version follows the compiler version; CLI and runtime component package versions remain independent.

See [advanced language support and boundaries](https://github.com/d-osc/DevLang/blob/v0.4.0/docs/advanced.md) and [runtime documentation](https://github.com/d-osc/DevLang/blob/v0.4.0/docs/runtime.md).

## Validation

Validated on Windows and Linux: 149 language-feature scenarios and 40 safety/aggregate-FFI scenarios. Linux additionally passed 27 native ASan/UBSan scenarios. Workspace tests and strict Clippy checks passed. Release archive generation verifies package checksums; extracted Windows and Linux archives passed compiler-free runtime continuation/callback checks.
